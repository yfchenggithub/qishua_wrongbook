# 七刷错题本 - 验收测试清单（MVP）

适用环境：Windows + VSCode + Codex，使用 Web 预览、Android 真机或 Android 模拟器进行验收。

## 1. 项目启动验收
- [ ] `npm install` 可以成功
- [ ] `npx expo start` 可以启动
- [ ] 按 `w` 可以打开 Web 预览
- [ ] `npx expo run:android` 可以安装到 Android 真机或模拟器
- [ ] App 可以正常打开

## 2. 页面骨架验收
- [ ] 首页可以打开
- [ ] 错题列表页可以打开
- [ ] 录入错题页可以打开
- [ ] 设置页可以打开
- [ ] 底部 Tab 可以正常切换
- [ ] 页面没有明显红屏报错

## 3. 拍照功能验收（后续实现后使用）
- [ ] 点击拍照按钮可以打开相机
- [ ] 用户取消拍照不会崩溃
- [ ] 拍照后页面可以显示图片
- [ ] 重启 App 后图片仍然存在
- [ ] 保存的是持久化 uri，不是临时 uri

## 4. SQLite 验收（后续实现后使用）
- [ ] 数据库可以初始化
- [ ] 可以创建一条错题
- [ ] 可以查询错题列表
- [ ] 关闭 App 后重新打开，错题仍然存在

## 5. 录入错题验收（后续实现后使用）
- [ ] 没有题目照片不能保存
- [ ] 保存成功后有提示
- [ ] 保存成功后错题出现在列表
- [ ] 保存成功后可以进入详情页

## 6. 7 次重做验收（后续实现后使用）
- [ ] 新错题显示 `0/7`
- [ ] 完成一次后变成 `1/7`
- [ ] 每次重做生成 `review_record`
- [ ] 做满 7 次后状态变成 `mastered`
- [ ] 已掌握错题不再出现在今日待复习

## 7. Codex 每轮修改验收
- [ ] 是否只完成本轮任务
- [ ] 是否修改了无关文件
- [ ] 是否破坏已有页面
- [ ] 是否有 TypeScript 报错
- [ ] 是否有控制台异常
- [ ] 是否更新了必要文档
