# 七刷错题本 - 验收测试清单（MVP）

适用环境：Windows + VSCode + Codex，使用 Web 预览、Android 真机或 Android 模拟器进行验收。

## 1. 项目启动验收
- [ ] `npm install` 可以成功
- [ ] `npx expo start` 可以启动
- [ ] 按 `w` 可以打开 Web 预览
- [ ] `npx expo run:android` 可以安装到 Android 真机或模拟器
- [ ] App 可以正常打开

## 2. 页面骨架验收
- [ ] 首页可以打开
- [ ] 错题列表页可以打开
- [ ] 录入错题页可以打开
- [ ] 设置页可以打开
- [ ] 底部 Tab 可以正常切换
- [ ] 页面没有明显红屏报错

## 3. 拍照功能验收（后续实现后使用）
- [ ] 点击拍照按钮可以打开相机
- [ ] 用户取消拍照不会崩溃
- [ ] 拍照后页面可以显示图片
- [ ] 重启 App 后图片仍然存在
- [ ] 保存的是持久化 uri，不是临时 uri

## 4. SQLite 验收（后续实现后使用）
- [ ] 数据库可以初始化
- [ ] 可以创建一条错题
- [ ] 可以查询错题列表
- [ ] 关闭 App 后重新打开，错题仍然存在

## 5. 录入错题验收（后续实现后使用）
- [ ] 没有题目照片不能保存
- [ ] 保存成功后有提示
- [ ] 保存成功后错题出现在列表
- [ ] 保存成功后可以进入详情页

## 6. 7 次重做验收（后续实现后使用）
- [ ] 新错题显示 `0/7`
- [ ] 完成一次后变成 `1/7`
- [ ] 每次重做生成 `review_record`
- [ ] 做满 7 次后状态变成 `mastered`
- [ ] 已掌握错题不再出现在今日待复习

## 7. Codex 每轮修改验收
- [ ] 是否只完成本轮任务
- [ ] 是否修改了无关文件
- [ ] 是否破坏已有页面
- [ ] 是否有 TypeScript 报错
- [ ] 是否有控制台异常
- [ ] 是否更新了必要文档

## 9. 录入草稿体验验收补充（第5步）

- [ ] 保存中按钮显示“保存中...”，且不可重复点击。
- [ ] 校验失败时页面可见错误文案（至少包含：请先拍题目照片、请选择模块、难度不合法）。
- [ ] 保存成功后提示“错题已加入 7 刷计划”，并显示 mistakeId。
- [ ] 保存成功后草稿重置：新 draftId、图片预览清空、模块/错因/难度恢复默认、标题/备注清空。
- [ ] 删除图片失败时有提示且页面不崩溃。
- [ ] 风险记录：未保存草稿图片可能残留在本地目录，后续可增加“放弃草稿时删除 draftId 目录”能力。

## 10. 第5步录入错题联合验收（5-G）

- [ ] 打开新增页。
- [ ] 拍题目照片。
- [ ] 可选拍做法照片。
- [ ] 可选拍答案照片。
- [ ] 选择模块。
- [ ] 选择错因。
- [ ] 选择难度。
- [ ] 点击保存。
- [ ] 打开 `/dev/db`。
- [ ] 点击“查询最近10条错题”。
- [ ] 确认 `mistakes` 有记录（含 id/module/difficulty/question_image_uri 等字段）。
- [ ] 在该记录上点击“查看该错题图片记录”。
- [ ] 确认 `mistake_images` 有图片记录（type/uri/created_at）。
- [ ] 确认每条图片 `exists = true`。
- [ ] 关闭 App 后重启。
- [ ] 再次打开 `/dev/db`。
- [ ] 数据仍然存在。
