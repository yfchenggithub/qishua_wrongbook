# Prompt 02 - Skeleton

## 任务目标
- 完成第一版页面骨架：首页、错题列表页、录入错题页、设置页。
- 接通基础路由与 Tab 切换，先确保信息架构可用，再进入业务实现。

## 明确不做
- 不接入 SQLite，不做真实数据读写。
- 不接入拍照与图片持久化。
- 不实现复杂状态管理与业务规则计算。

## 需要修改的文件类型
- 路由与页面文件：`app/**/*.tsx`
- 轻量展示组件：`src/components/**/*.tsx`
- 页面常量与占位文案：`src/constants/**/*.ts`
- 对应文档：`docs/*.md`

## 验收标准
- 首页、错题列表页、录入错题页、设置页都可打开。
- 底部 Tab 可正常切换。
- 页面无明显红屏错误。
- 不引入业务耦合代码（SQL、文件系统、复杂服务逻辑）。
