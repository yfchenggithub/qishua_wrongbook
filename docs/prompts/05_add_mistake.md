# Prompt 05 - Add Mistake

## 任务目标
- 打通"录入错题"最小闭环：填写信息、关联题目图/答案图、提交保存。
- 保存后可在错题列表看到新记录，并可进入详情页。

## 明确不做
- 不做复杂筛选、排序、统计分析。
- 不做云同步与多设备共享。
- 不做与录入闭环无关的页面重构。

## 需要修改的文件类型
- 录入与列表页面：`app/**/*.tsx`
- 数据访问与服务：`src/repositories/**/*.ts`、`src/services/**/*.ts`
- 数据模型与常量：`src/models/**/*.ts`、`src/constants/**/*.ts`
- 对应文档：`docs/testing.md`、`docs/data_contract.md`

## 验收标准
- 没有题目照片时不能保存。
- 保存成功后有明确提示。
- 保存成功后错题出现在列表。
- 从列表可以进入对应详情页。
