# Prompt 01 - Guardrails

## 任务目标

- 本阶段只做工程护栏建设：完善 `AGENTS.md`、补齐 `docs/` 文档、补充脚本规划、设计 `Logger` 的基础约定或占位。
- 保证后续任务可按小步迭代推进，并且每轮都有可验收标准。

## 明确不做

- 不实现错题录入、列表、详情、7 次复习等业务功能。
- 不接入云服务、登录、支付、会员、社区等非 MVP 能力。
- 不做大重构，不改动无关页面与无关模块。

## 需要修改的文件类型

- 文档文件：`docs/**/*.md`、`AGENTS.md`
- 脚本与配置文件：`package.json`（仅 scripts）、`scripts/*`
- 基础日志相关文件：`src/**/Logger*.ts`（仅基础能力，不接业务）

## 验收标准

- 文档与规范齐全，且彼此一致。
- 脚本可用或明确标注"建议后续补充"。
- Logger 仅为基础设施，不耦合业务流程。
- 项目可正常启动，无新增明显报错。
