# 七刷错题本 - 产品文档（MVP）

## 1. 产品一句话定位
一个完全离线的高中数学错题记录 App，帮助学生把每道错题重做 7 次。

## 2. 核心用户
- 高中学生
- 高中数学老师
- 教培老师
- 需要管理错题复习计划的人

## 3. MVP 核心闭环
录入错题 → 拍题目照片 → 拍答案/解析照片 → 本地保存 → 查看错题列表 → 进入详情 → 开始重做 → 拍本次做法 → review_count +1 → 做满 7 次 → 标记已掌握。

## 4. 第一版页面
- 首页：今日待复习
- 录入错题页
- 错题列表页
- 错题详情页
- 重做页面
- 设置页

## 5. 第一版功能范围
- 本地录入错题
- 本地保存图片 uri
- 本地 SQLite 保存元数据
- 错题列表
- 错题详情
- 7 次重做记录
- 今日待复习

## 6. 第一版明确不做
- 登录
- 云同步
- OCR
- AI 批改
- 支付
- 会员
- 社区
- 分享
- 复杂统计
- 多设备同步
- 服务器接口

## 7. 产品验收标准
- 可以录入一道错题
- 可以保存题目照片
- 可以保存答案照片
- 关闭 App 后数据仍然存在
- 可以完成第 1 次重做
- 0/7 可以变成 1/7
- 做满 7 次后状态变成已掌握
