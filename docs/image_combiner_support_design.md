# 多图合并外部工具支持设计

## 1. 需求定位
- 当用户一次拍摄或选择了多张题目、答案、解析图片，但希望在错题本里只保存一张图片时，可以自行使用外部网页工具先把多张图片合并成一张。
- 本功能只是在 App 内提供“使用说明 + 链接复制”支持，不做 App 内置图片合并能力。
- 推荐工具：`https://imagecombiner.com/`。

## 2. 明确不做
- 不在 App 内实现拼图、画布、网格、拖拽排序等图片合并功能。
- 不内嵌 WebView。
- 不调用 imagecombiner.com 的接口。
- 不把用户图片从七刷错题本上传到任何服务器。
- 不自动读取、保存、下载网页生成的图片。
- 不新增数据库字段，不修改现有图片存储契约。

## 3. 入口位置
- 入口放在：设置页 -> 关于与支持。
- 在“官方公众号”和“问题反馈”之间增加一个轻量说明卡片。
- 卡片归类为“外部工具推荐”或“多图合并说明”，避免用户误以为这是 App 内置功能。

## 4. 页面文案建议

### 卡片标题
多图合并成一张

### 卡片说明
如果一道题被拍成多张图片，可以先用外部网页把图片合并成一张，再回到七刷错题本选择合并后的图片。

### 隐私提示
七刷错题本不会读取网页中的图片，也不会接收网页生成结果。请在浏览器中自行完成合并和保存，再手动导入 App。

### 操作按钮
- 复制网址：复制 `https://imagecombiner.com/`
- 查看使用步骤：展开或弹出简短步骤说明

可选后续按钮：
- 打开外部网页：如果后续确认允许外链跳转，可用系统浏览器打开；默认阶段可以先不做。

## 5. 用户流程
1. 用户在“关于与支持”里看到“多图合并成一张”说明。
2. 点击“复制网址”，到浏览器打开 imagecombiner.com。
3. 在网页里选择多张本地图片，按需要选择横向、纵向或网格布局。
4. 在网页里下载合并后的单张图片。
5. 回到七刷错题本，在录入错题、答案图片或复做图片位置选择这张合并后的图片。
6. App 仍按现有 `ImageService` 和 `mistake_images.uri` 规则保存这张图片。

## 6. 技术边界
- 页面层只负责展示说明和复制链接。
- 链接常量建议放在 `src/constants/app.ts`，例如 `IMAGE_COMBINER_URL`。
- 如果只做“复制网址”，可以复用 `app/about-support.tsx` 已有的 Clipboard 和 toast 逻辑。
- 不需要新增 service、repository、db schema。
- 合并后的图片进入 App 后，仍走现有图片导入、压缩、持久化链路。

## 7. 验收标准
- “关于与支持”页面能看到多图合并说明。
- 点击“复制网址”后，剪贴板内容为 `https://imagecombiner.com/`，并显示成功提示。
- 页面文案明确说明这是外部网页工具，不是七刷错题本内置合图能力。
- 不产生任何数据库结构变化。
- 不影响录入错题、错题详情、复做和备份恢复现有流程。

## 8. 风险与处理
- 外部网站内容或可用性可能变化：文案应避免承诺该网站永久可用。
- 外部网页隐私策略由网站方负责：App 内只做使用提示，不对网页处理过程背书。
- 用户可能误解为 App 会自动合并：标题和提示中必须写清“外部网页”“手动保存后再导入”。
